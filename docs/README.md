## What is JellyPlay?

JellyPlay is a **self-hosted media player for Android and Android TV**,
designed to be the best companion app for your [Jellyfin](https://jellyfin.org/)
server. It is:

- 🪶 **Native** — written in Kotlin and Jetpack Compose from scratch
  (not a web wrapper).
- 📺 **Universal** — one app, every form factor: phones, tablets, foldables,
  Android TV, and Amazon Fire TV.
- 🎬 **Multi-engine** — pick between ExoPlayer / Media3, libmpv, and
  LibVLC for video playback.
- 🪪 **Open source** — GPL-3.0, no telemetry, no accounts, no ads.
