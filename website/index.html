Your Jellyfin server,
re-imagined for every screen

JellyPlay is a high-fidelity, open-source media player for Jellyfin. Built with Kotlin and Jetpack Compose, it features dynamic color theming, offline downloads, and multi-engine playback — on phones, tablets, foldables, Android TV & Fire TV, with a Windows desktop preview and an experimental web build from the same shared codebase.

FAQ

Frequently Asked Questions

Everything from server setup and supported devices to engines, downloads, and privacy.

JellyPlay is a free, open-source Jellyfin client for Android phones, tablets, foldables, Android TV, and Fire TV — with a Windows desktop preview and an experimental web build. It is written natively in Kotlin and Jetpack Compose with Material 3 Expressive, not a web wrapper like the official Android app.

Yes. JellyPlay is licensed under the GNU GPL v3.0 — free to download, use, modify, and redistribute. No ads, no in-app purchases, no telemetry, and no accounts required.

Unlike the official client which acts as an HTML/Web wrapper, JellyPlay runs 100% natively on your device. This enables features like fluid Material 3 dynamic color generation, complex local SSA/ASS subtitle rendering using libmpv without server-side transcoding, and real-time gapless audio equalization.

JellyPlay includes three media pipelines. Use ExoPlayer for battery efficiency, HDR10+, and standard formats. Use libmpv if you stream heavy anime files requiring styled ASS subtitles or 10-bit color profile rendering. Use VLC as a backup pipeline for raw ISO file formats or legacy LAN streams.

Yes. Create or join a watch group, stay in real-time sync with friends, and use the in-player group chat. Server-time synchronization plus speed and skip-to-sync correction keep everyone in frame — try the interactive demo in the features section above.

Yes. Connect Jellyseerr or Overseerr to browse trending, popular, and upcoming content, request movies and shows via Radarr/Sonarr, and track request status with admin approve/decline actions — all without leaving the app.

JellyPlay features an enterprise-grade offline system powered by a custom WorkManager engine and OkHttp. It bundles not just media files, but all sibling assets — external subtitles, trickplay preview tiles, intro/outro markers, and rich metadata — into an offline-ready library. While offline, a durable playback outbox captures playback progress, stop events, and watched status, automatically syncing back to your Jellyfin server on reconnect with intelligent conflict reconciliation. It also includes selective freshness resync to update changed artwork or metadata without re-downloading videos.

Yes! JellyPlay compiles separate architectures specifically optimized for big screens. The TV builds feature a dedicated Leanback UI tailored for standard D-pad TV remotes, letting you navigate your movie library grids on Fire OS, Android TV, or Chromecast with Google TV without touch emulators.

A Windows desktop preview (Compose Multiplatform + bundled libmpv) already runs browsing, search, details, music, and in-player video — treat it as a preview, not a release. An experimental WebAssembly build signs in and plays video in the browser. Both ship from the same shared Kotlin codebase; check the Platforms section above and the release notes for current status.

No. JellyPlay is fully self-hosted: no analytics, no tracking, no phone-home, no cloud dependency. Your library, server connection, and viewing history stay between you and your Jellyfin server. Optional PIN/biometric lock and Kids Mode keep shared devices safe.
